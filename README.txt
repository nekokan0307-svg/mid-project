FITBEAT Motion Update v2

1. Open https://github.com/nekokan0307-svg/mid-project
2. Open art-ui.css, click the pencil icon, select all and replace its contents with the art-ui.css in this ZIP.
3. Commit changes.
4. Open the game, select a level, and use Left/Right/Up/Space (or on-screen buttons) to see different animations.

Only art-ui.css changes. All four approved background images and existing mascot are preserved.
This makes the same PNG image move differently; it does NOT animate individual limbs or facial expressions. For genuine pose-by-pose animation, we need separate transparent character frames.
